# Data Analyst Portfolio Project

## Retail Performance & Customer Insights Dashboard

This project was built to demonstrate the kind of work expected from a data analyst role: business question framing, data cleaning, exploratory analysis, KPI tracking, and executive-ready storytelling.

### Objective

Analyze a retail sales dataset to uncover:
- revenue and profit trends over time
- regional and channel performance
- top-selling product categories
- customer behavior patterns
- business opportunities for growth and retention

### Tools used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- GitHub for portfolio presentation

### Dataset

The project uses a synthetic retail dataset generated for portfolio demonstration. It includes customer, order, product, region, and sales information.

### Deliverables

- cleaned dataset in `data/retail_sales_data.csv`
- analytics script in `analyze_retail.py`
- dashboard image in `outputs/data_analyst_dashboard.png`
- business summary in `outputs/insights_summary.md`
- monthly and category performance CSVs in `outputs/`

### Key business insights

- revenue rises steadily across the year with a strong peak in Q4
- online sales and marketplace channels outperform traditional retail in terms of both volume and margin
- regional performance is strongest in the North and West markets
- high-ticket categories drive more profit, while discount-heavy categories generate higher units sold
- customer retention and repeat purchase optimization remain the biggest growth levers

### Recommended next steps

- segment customers by order frequency and value
- test targeted promotions in low-performing regions
- optimize pricing and discount strategy by category
- build a live Power BI dashboard for non-technical stakeholders

### Run locally

```bash
cd projects/data-analyst-capstone
python analyze_retail.py
```
